## Stars&Stacks v1.0.0

![Stars&Stacks Banner](/images/Stars-Stacks/Banner.png)

I'm excited to announce the release of **Stars&Stacks v1.0.0** — a native Android application for tracking a personal precious metals portfolio. *Stack metals, not promises.*

### About the Application

Stars&Stacks helps you log purchases and sales, view derived holdings and cost basis, back up data to CSV, and monitor stack value against live spot prices for gold, silver, and platinum.

### What's New in v1.0.0

This initial release is **offline-first**, with portfolio data stored locally using Room. Spot prices for **XAU**, **XAG**, and **XPT** are fetched via MetalpriceAPI in a user-selected base currency (**USD** by default; also **CAD**, **AUD**, **GBP**, and **EUR**).

Purchases and sales support **FIFO**, **LIFO**, and **Average** cost-basis methods. The **Dashboard** includes a live metal ticker, Holdings and Lifetime portfolio summary (with premium over spot), metal allocation by value chart, My Stack by metal, and Stacking Activity (12-month purchase stats plus a 6-month spend chart). **My Stack** product detail shows open lots, history, and spot to break even. **Settings** provides theme mode, CSV export/import, and portfolio data reset.

Adaptive layouts provide two-pane list-detail on tablets and landscape, with NavigationRail on wider screens.
