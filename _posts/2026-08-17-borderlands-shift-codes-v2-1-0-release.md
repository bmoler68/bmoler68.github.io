## Borderlands SHiFT Codes v2.1.0

![Borderlands SHiFT Codes Banner](/images/BorderlandsSHiFTCodes/Banner.png)

I'm excited to announce the release of **Borderlands SHiFT Codes v2.1.0**. This release fixes a hard app error that could appear when a remote sync to Supabase failed, which prevented locally stored SHiFT codes from being viewed.

### About the Application

Borderlands SHiFT Codes is an unofficial fan project designed to provide easy access to SHiFT codes for the Borderlands and Wonderlands gaming universe. This Android application serves as a convenient way to view and manage codes that can be redeemed on the official Gearbox SHiFT website or directly in-game.

### What's New in v2.1.0

Fixed a hard app error that displayed when a remote sync to Supabase failed. That error blocked access to the local code list, so previously stored SHiFT codes could not be viewed. The app now handles a failed remote sync with a warning message, so local codes remain available to browse.
