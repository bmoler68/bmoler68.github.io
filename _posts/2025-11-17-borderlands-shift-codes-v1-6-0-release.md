## Borderlands SHiFT Codes v1.6.0 - Open Source Release

I'm excited to announce the release of **Borderlands SHiFT Codes v1.6.0** and the open sourcing of this application! This version marks a significant milestone as the codebase is now publicly available on GitHub under the MIT License.

### About the Application

Borderlands SHiFT Codes is an unofficial fan project designed to provide easy access to SHiFT codes for the Borderlands and Wonderlands gaming universe. This Android application serves as a convenient way to view and manage codes that can be redeemed on the official Gearbox SHiFT website or directly in-game.

### What's New in v1.6.0

This release represents the **open source release** of the application. The complete source code is now available on GitHub.
