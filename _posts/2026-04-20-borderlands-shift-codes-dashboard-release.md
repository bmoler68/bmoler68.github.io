## Borderlands SHiFT Codes Dashboard Now Live

![Borderlands SHiFT Codes Banner](/images/BorderlandsSHiFTCodes/Banner.png)

I'm excited to announce the launch of the **Borderlands SHiFT Codes Dashboard** on my website at [brianmoler.com](https://www.brianmoler.com), available here: [Borderlands SHiFT Codes Dashboard](https://www.brianmoler.com/shift-codes-dashboard/shift-codes-dashboard.html).

### A Companion to the Mobile App

The dashboard is designed as a web companion to the **Borderlands SHiFT Codes** Android app. It offers very similar functionality to the mobile app, but in a larger desktop browser layout so it is easier to browse, filter, and redeem codes.

### What the Dashboard Does

The dashboard includes summary cards for Borderlands, Borderlands 2, Borderlands 3, Borderlands 4, The Pre-Sequel, and Wonderlands, along with a detailed codes table with search, filtering, and one-click code copy to make finding and redeeming codes faster.  There is also a button to quickly access the Gearbox SHiFT website to redeem active codes.

### Chart Highlights

I was able to incorporate some charts into the dashboard.  The charts are designed to give a quick at-a-glance view of code frequency and quality for each game. **New Codes Over Time** helps you spot recent SHiFT code drops, **Status Breakdown** shows the balance of active and expired codes, and **Code Type Breakdown** highlights the mix of rewards like Keys, Cosmetics, and Gear.

All charts update as you switch games, so you can get a quick visual summary of the the detailed code list contents.

The overall goal of this release is to provide a web companion to the mobile app, with visual trends and filterable details that make it easy to find redeemable codes quickly.
