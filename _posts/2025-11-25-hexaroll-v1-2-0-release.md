## HexaRoll v1.2.0 - Open Source Release

![HexaRoll Banner](/images/HexaRoll/banner.png)

I'm excited to announce the release of **HexaRoll v1.2.0** and the open sourcing of this application! This version marks a significant milestone as the codebase is now publicly available on GitHub under the MIT License.

### About the Application

HexaRoll is a modern Android dice rolling application designed specifically for tabletop RPG gaming. Featuring five distinct visual themes, it provides a comprehensive dice rolling experience with 8 different polyhedral dice types, persistent roll history, and a comprehensive achievement system.

### What's New in v1.2.0

This release represents the **open source release** of the application. The complete source code is now available on GitHub.

Additionally, this version includes significant **image asset optimization** which has greatly reduced the APK size and improves overall performance of the app.
